# Projeto Vetores e Fatorial em C

Repositório acadêmico desenvolvido para a disciplina, aplicando conceitos de modularização em C, manipulação de vetores, gerenciamento de memória com tipos `long` e automação de compilação.

## 📂 Estrutura do Projeto

- **`src/`**: Contém o código-fonte modularizado.
  - `desafio.c`: Programa principal (`main`).
  - `vetores.c`: Implementação das funções.
  - `vetores.h`: Interface (cabeçalho).

## 🚀 Como Compilar e Executar

Este projeto utiliza um **Makefile** para facilitar a compilação. Na raiz do repositório, basta executar:

```bash
make
./programa
