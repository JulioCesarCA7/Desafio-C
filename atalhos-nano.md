# Guia de Atalhos - Editor Nano

Referência rápida de comandos para navegação e edição no terminal.

### ⚙️ Comandos Essenciais
```text
Ctrl + O  : Salvar arquivo
Ctrl + X  : Sair do nano
Ctrl + G  : Ajuda geral

Ctrl + K  : Recortar / Apagar linha
Ctrl + U  : Colar texto
Alt + A   : Iniciar selecao (ou Ctrl + 6)
Alt + 6   : Copiar selecao
Alt + U   : Desfazer (Undo)
Alt + E   : Refazer (Redo)

Ctrl + W  : Buscar palavra
Ctrl + \  : Substituir palavra
Ctrl + _  : Ir para linha (digite o numero)
Alt + \   : Pular para o INICIO do arquivo
Alt + /   : Pular para o FINAL do arquivo
